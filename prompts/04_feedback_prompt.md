# Step 4: Feedback Prompt

## Human Prompt
```text
I played the game and found these issues:

1. The opponents are difficult to distinguish.
2. The first fruit appears too slowly.
3. The death animation is unclear.

Fix all three issues.
```

## Prompt Engineering Context (2026 Methodology)
* **Goal**: Specific bug fixing and playtesting friction elimination.
* **Key Concept**: "Give specific, numbered feedback." Vague complaints like "make it better" yield unpredictable AI edits. Concise, enumerated observations anchored in direct experience produce targeted surgical fixes.
* **Expected Output**:
  1. High-contrast neon color schemes and distinct name labels for opponents.
  2. Immediate pre-population of 5 fruits on game start.
  3. Visual particle explosion and impact feedback when any snake crashes.
