# Step 2: Customization Prompt

## Human Prompt
```text
Can I pick my snake's color before the game starts?
```

## Prompt Engineering Context (2026 Methodology)
* **Goal**: Feedback-driven iteration based on user observation.
* **Key Concept**: "Notice what you wish were different." After testing the raw baseline, the user recognizes that personal agency and visual ownership are missing.
* **Expected Output**: A pre-game setup screen / lobby menu containing color selection inputs, palette previews, and instant reactive state management before the loop starts.
