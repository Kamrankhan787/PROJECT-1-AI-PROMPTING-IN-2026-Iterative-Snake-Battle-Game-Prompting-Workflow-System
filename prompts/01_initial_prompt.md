# Step 1: Initial Prompt

## Human Prompt
```text
Let's build and play a game where a snake eats fruit balls to grow.
```

## Prompt Engineering Context (2026 Methodology)
* **Goal**: Establish the immediate interactive artifact baseline with minimum friction.
* **Key Concept**: "Start with an experience." Rather than writing a massive 50-page specification up front, generate a functional MVP immediately so human playtesting can begin.
* **Expected Output**: A playable canvas/grid with a moving snake, keyboard input, single fruit spawn, growth on collision, and basic death boundary condition.
